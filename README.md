💹 Compound Interest Calculator in Java
A beginner-friendly project with a touch of DSA magic ✨
Welcome to this Compound Interest Calculator built in Java! 🚀
This simple but powerful program helps you compute your future savings or investment returns using the compound interest formula — and also gives you a year-by-year breakdown 📊 using arrays (DSA intro).

🔧 Features
💼 Calculates compound interest using:
A = P(1 + r/n) ^ (nt)

📥 Takes input for:

Principal amount

Annual interest rate

Number of compoundings per year

Duration in years

📊 Shows interest accumulation for each year

🧠 Uses arrays to store and display annual amount snapshots

🧠 What You Learn From This Project

Concept	Description
✅ Scanner Input	Taking and validating user inputs
✅ Math.pow()	Exponentiation used for compound interest formula
✅ printf formatting	Neatly displaying financial output (%.2f for 2 decimal places)
✅ Arrays (DSA element)	Storing yearly growth values for tracking and analysis
✅ Loops & Conditions	for loop used to calculate interest year-by-year
